# assistant-ui assets

All drawn for Kristall OS, GPL-3.0-or-later; no third-party artwork.

| file | what | source |
|---|---|---|
| `assets/cursor.svg` | the assistant's cursor: a two-facet crystal shard in a pointer outline | drawn by hand for this module |
| `shaders/edgelight.frag` (+ `.qsb`) | the crystal light | written for this module; `.qsb` built by `tools/gen-shaders.sh` (Qt Shader Tools) |

Symbols used at run time come from the shell's bundled Phosphor set (MIT, `shell/ASSETS.md`) and our
`kristall/assistant` symbol. Test wallpapers are generated by `tests/support.py` (`aurora`) or taken
from the glass suite's stress pattern (`busy`).
