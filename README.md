# Kristall OS

Ein Betriebssystem für einen Laptop, das sich anfühlt wie ein Mac: echtes Liquid Glass, eine Menüleiste, ein Dock, ein Kontrollzentrum und ein eingebauter Assistent, der Deutsch versteht und Dinge am Computer für dich erledigt.

*An operating system for one laptop that feels like a Mac: real Liquid Glass, a menu bar, a Dock, a Control Center, and a built-in assistant that understands German and gets things done on the computer for you.*

- **Installieren / Install:** [docs/INSTALL.md](docs/INSTALL.md)
- **Wie es gebaut ist / How it is built:** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

Kristall OS basiert auf Fedora Kinoite (KDE Plasma) als unveränderliches Image mit automatischen Updates. Der Assistent nutzt dein eigenes Claude-Konto über Claude Code.

*Kristall OS is built on Fedora Kinoite (KDE Plasma) as an immutable image with automatic updates. The assistant uses your own Claude account through Claude Code.*
